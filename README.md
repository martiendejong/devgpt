# DevGPT is now Hazina

**This repository has been archived.** DevGPT has evolved into **Hazina** — a production-ready AI framework for .NET.

## 🔗 Migrate to Hazina

**New Repository:** https://github.com/martiendejong/Hazina

Hazina is the next generation of DevGPT with:
- ✅ Production-ready architecture
- ✅ Advanced RAG capabilities
- ✅ Multi-agent orchestration
- ✅ Built on Semantic Kernel
- ✅ Full .NET 9 support
- ✅ NuGet packages available

## Why the Change?

DevGPT was built as a research framework to explore agentic AI patterns. Hazina takes those learnings and delivers a production-grade framework with:
- Better architecture
- Cleaner APIs
- Professional documentation
- Active maintenance
- Community support
